# D1ALERT — Offline-First Emergency Alert System

> **QUANTA Presentation & Pitch Deck**  
> An executive, offline-first emergency alert platform tailored for the Philippines — built for immediate response during life-threatening crises without reliance on mobile data or Wi-Fi.

---

## 🚨 Problem & Solution Overview

* **The Problem:** Delayed emergency reporting, heavy dependence on internet connectivity (only 48.8% of Philippine households had home internet in 2024), difficulty communicating precise coordinates during panic, and extreme risk during silent/duress situations (assault, stalking, robbery).
* **The Solution:** D1ALERT combines on-device acoustic event detection (**YAMNet**), offline speech recognition (**Vosk**), lightweight emergency classification (**MLP classifier**), discreet physical-button activation, GPS fallback positioning, and structured SMS alerts routed directly to authorized emergency dispatchers for human validation.
